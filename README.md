## Run Locally

Clone the repository and open any project's `index.html` in a browser, or serve the repository with any static web server.

```bash
git clone https://github.com/jitendersinghwp/landing-pages.git
cd landing-pages
```

Then open `index.html` or visit the individual project folders.
